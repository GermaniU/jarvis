🧠 PERFIL DEL USUARIO Y FUNCIONALIDAD DE JARVIS

El usuario es un programador que trabaja principalmente con tecnologías como .NET Core, Angular, Strapi, Docker, y AWS. Tiene conocimientos intermedios-avanzados en DevOps, infraestructura local, multi-tenant, y proyectos de inteligencia artificial. Usa Ollama con modelos como DeepSeek y Nomic Embed para procesamiento local.

La máquina del usuario tiene una GPU NVIDIA RTX 3050, la cual se aprovecha para ejecutar modelos locales y tareas intensivas en IA. Jarvis fue configurado para aprovechar esta GPU y ejecutar modelos como DeepSeek 14B con memoria persistente usando LlamaIndex.

🧠 FUNCIONES ACTIVAS DE JARVIS

1. **Memoria persistente:** Almacena cada interacción en archivos `.txt` dentro del directorio `memory/`. Estos recuerdos se indexan automáticamente y se pueden recuperar por contexto.
2. **Recuperación contextual:** Usa VectorStoreIndex para buscar recuerdos relevantes y responder basándose en información previa.
3. **Embeddings locales:** Utiliza el modelo `nomic-embed-text` de Ollama para generar embeddings locales, sin conexión a internet.
4. **Instrucciones avanzadas:** Jarvis ha sido configurado para NUNCA decir que "no recuerda" si tiene recuerdos disponibles.
5. **Respuestas en español:** Jarvis responde siempre en español, con lenguaje claro, contextual y empático.
6. **Motor de chat contextual:** El sistema está configurado con `ContextChatEngine` y `ChatMemoryBuffer` para mantener contexto dentro de cada sesión.
7. **Alimentación de recuerdos externos:** También se puede alimentar la memoria cargando archivos `.txt` o `.md` en las carpetas `data/` y `memory/`.
